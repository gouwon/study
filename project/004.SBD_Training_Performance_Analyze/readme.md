# 🏋️ Smart Workout Guide & Level Analyzer
> **데이터 기반의 개인 맞춤형 스트렝스 가이드 및 SBD 레벨 분석 도구**

이 프로그램은 사용자의 현재 체중과 운동 목적(스트렝스, 근비대, 근지구력)에 맞춰 최적의 운동 강도를 산출하고, 수행 결과를 바탕으로 **점진적 과부하(Progressive Overload)** 가이드와 **SBD 레벨**을 분석해 줍니다.

---

## 🚀 주요 기능

### 1. 목적별 가중치($W$) 시스템
선택한 운동 목적에 따라 세트 수, 반복 횟수, 휴식 시간을 자동으로 조정합니다.
- **스트렝스 (1.2):** 고강도 저반복, 충분한 휴식(3~5분)
- **근비대 (1.0):** 중강도 중반복, 표준 휴식(60~90초)
- **근지구력 (0.6):** 저강도 고반복, 짧은 휴식(30~60초)

### 2. 정밀한 1RM 추정 공식 적용
반복 횟수 범위에 따라 가장 신뢰도가 높은 공식을 선택하여 1RM을 계산합니다.
- **2~6회:** Brzycki 공식
- **7~12회:** Epley 공식
- **13회 이상:** Wathan 공식

### 3. 실시간 컨디션 반영 웜업 가이드
이전 운동 기록과 당일 수행한 웜업 컨디션을 비교하여 오늘 최적으로 수행할 수 있는 '본 운동' 무게를 제안합니다.

### 4. SBD 기반 레벨링 시스템
체중 대비 3대 운동(스쿼트, 벤치프레스, 데드리프트) 추정 합계를 계산하여 사용자의 수준을 5단계로 분류합니다.
- **Elite** 🔥 / **Advanced** 💪 / **Intermediate** 🏋️ / **Novice** 🚴 / **Beginner** 🚶

---

## 🛠️ 사용 방법

1. **체중 입력:** 현재 체중(kg)을 입력합니다.
2. **목적 선택:** 스트렝스, 근비대, 근지구력 중 오늘 운동의 목적을 선택합니다.
3. **웜업 수행:** 프로그램이 제안하는 웜업 무게와 횟수를 수행하고 결과를 입력합니다.
4. **본 운동 수행:** 총 4세트의 본 운동 결과를 입력합니다.
5. **결과 확인:** - 세트 성공 여부 판정 (증량/유지/검토)
   - 현재 추정 SBD 레벨 및 다음 단계까지 필요한 증량치 확인
   - 수준에 맞는 추천 운동 장비 가이드 확인

## 📊 레벨 기준표 (SBD Ratio)



| 레벨 | SBD 비율 (체중 대비) | 가이드 및 추천 장비 |
| :--- | :---: | :--- |
| **Elite** | 8.00배 이상 | 최고 수준 근력 / 자유로운 프리웨이트 |
| **Advanced** | 6.50배 이상 | 근육 밀도 극대화 / 해머 스트렝스 ISO |
| **Intermediate** | 4.50배 이상 | 불균형 해소 / 해머 스트렝스 MTS |
| **Novice** | 2.80배 이상 | 기초 근력 및 프레임 확장 / 셀렉트 머신 |
| **Beginner** | 0.00배 이상 | 기초 근신경계 발달 / 라이프니스, 테크노짐 |

## 💻 코드 구조 (주요 함수)

- `calculate_1rm(weight, reps)`: 반복 횟수별 최적화된 공식을 활용한 1RM 산출
- `round_to_plate(weight)`: 실제 헬스장에서 원판으로 구현 가능한 2.5kg 단위 반올림
- `calculate_plate_distribution(total_weight)`: 바벨에 끼워야 할 원판 조합 계산
- `get_level_info(ratio)`: SBD 비율에 따른 현재 레벨 및 목표 레벨 반환
